

PROYECTO LIFTING UP - Grupo 8

Descripcion del proyecto:
El proyecto consiste en el desarrollo de una aplicación móvil destinada a la digitalización de rutinas 
de entrenamiento y al seguimiento de asistencia de usuarios en un gimnasio.

El sistema permitirá a los usuarios gestionar sus rutinas de entrenamiento, registrar su progreso 
físico, consultar ejercicios disponibles y organizar su calendario de actividad deportiva. Además, 
brindará herramientas administrativas para gestionar el equipamiento del gimnasio, mantener un 
catálogo de ejercicios y visualizar estadísticas de asistencia.

La aplicación estará orientada a la gestión de catálogos dinámicos de información, al 
almacenamiento de registros históricos de entrenamiento y al desarrollo de interfaces visuales 
enfocadas en la visualización de datos.
